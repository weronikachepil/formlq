# Фіча «Дошки»

Інтерактивна дошка для уроків математики (перенесена з MathBoard): малювання, фігури й побудови, графіки, тіла, формули (MathLive), аркуші, тести з автоперевіркою, голосування, таймер, коментарі, «слідкуй за мною», лазерна указка, версії.

---

## 1. Ролі та маршрути

| Хто | Де | Що може |
|-----|----|---------|
| будь-який акаунт | `/tutor/boards` (вчитель, редактор) або `/dashboard/boards` (учень) | створює свої дошки, ділиться посиланням, перейменовує, видаляє; бачить «Доступні мені» — чужі дошки, які відкривав |
| власник дошки | `/board/[id]` | усе на дошці + доступ учасників, версії, посилання |
| будь-який акаунт formlq | `/board/[id]` (за посиланням) | учасник; імʼя береться з профілю |

Відкриті чужі дошки запамʼятовуються в `users/{uid}/boardVisits/{boardId}` (`{ title, ownerName, visitedAt }`), видимі лише самому користувачу; видалені дошки зі списку відфільтровуються.

Без входу `/board/[id]` перенаправляє на `/login?next=…`.

## 3. Дані

### Firestore `boards/{id}` — лише для списку
```
{ ownerId, ownerName, title, createdAt, updatedAt }
```

### Realtime Database `boards/{id}`
```
meta                 { owner, edit, protect }    — доступ учнів
objs/{oid}           конверт обʼєкта             — бачать усі
own/{uid}/{oid}      конверт                     — бачать учень uid і власник
hidden/{oid}         конверт                     — лише власник
keys/{quizId}        { key, expl?, explImg? }    — ключі невідкритих тестів, лише власник
live/peers/{cid}     { uid, name, color, owner } — присутність (onDisconnect)
live/cur|laser/{cid} курсори, лазер
live/view            вигляд вчителя («слідкуй»)
live/pview/{cid}     де зараз учень (лише власник)
live/goto            { pg }                      — «запустити тест» для всіх
boardVersions/{id}/{vid}   { ts, label, count }
boardSnapshots/{id}/{vid}  JSON усіх обʼєктів
```

**Конверт** = поля, потрібні правилам (`t`, `z`, `by`, `pg`, `lock`, `vis`, для аркушів `for/test/closed/endsAt`) + увесь обʼєкт рядком JSON у `d`. Рядок, бо RTDB псує масиви й порожні обʼєкти.

**Куди потрапляє обʼєкт** ([bucketOf](../src/lib/board/buckets.ts)):
- відповіді, «здано», бали → `own/{автор}`;
- аркуш-чернетка тесту та шаблон «кожному окремий листок» → `hidden`; особистий приватний аркуш → `own/{учень}`;
- решта — туди ж, де їхній аркуш. Коли аркуш змінює видимість (вчитель запускає тест), його вміст переїжджає разом із ним.

## 4. Права ([database.rules.json](../database.rules.json))

Перенесено з серверного `perm.mjs`:
- власник може все;
- учень створює обʼєкти лише зі своїм `by`; не змінює заблоковані (`lock`); при «захисті» змінює/видаляє лише своє (на чужі коментарі може відповідати);
- аркуші, таймер, голосування, картки завдань, тести, бали — лише власник;
- відповідь на тест — лише своя, до здачі, до завершення тесту й до `endsAt` (серверний `now`);
- здачу тесту скасувати не можна;
- приватні аркуші й ключі тестів іншим учням не надсилаються взагалі.

Правила генеруються з виразів — при зміні стежте, щоб `objs`/`own` лишались узгодженими з `bucketOf`.

## 5. Логіка вчителя замість сервера

[BoardHost](../src/lib/board/host.ts) працює у вкладці власника:
- учень здав тест → рахує бал (`score_{pg}_{uid}`);
- вчитель завершив тест (або минув `endsAt`) → «здано» й бал усім, хто відповідав;
- режим «кожному окремий листок» → копія аркуша кожному учню, що на дошці або зайде пізніше;
- при відкритті дошки доганяє пропущене: бали за здачі без вчителя, прострочені тести.

Поки вчителя немає на дошці, бали не зʼявляються (зʼявляться, щойно він відкриє дошку). Закриття відповідей працює й без нього — це перевіряють правила.

Версії: автоматично не частіше ніж раз на 10 хв (поки власник на дошці), до 40 штук; вручну — у діалозі «Версії».

## 6. Розгортання

```bash
firebase deploy --only database,firestore:rules
```
